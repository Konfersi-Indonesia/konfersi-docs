The **Konfersi Lab** extension brings the whole Lab workspace into a desktop code editor. It's the same extension that runs Lab in your browser, so every view, command and result is the same.

Supported editors: **VS Code** and **Antigravity**. Other editors built on VS Code (version 1.90 or later), such as Cursor, can also install the extension from its file.

## Browser or desktop?

| | Browser | Desktop editor |
|---|---|---|
| Install | Nothing | Install the extension once from a file |
| Sign in | Uses your Console session | Approve the editor once from your browser |
| Open a project | **Konfersi Lab** in the Console | **VSCode** or **Antigravity** in the Console, or **Konfersi: Switch Project…** |
| Saving files (charts, CSV, reports, NetCDF) | Downloaded by the browser | Saved with your system's save dialog |
| Updates | Always current | The extension updates itself |
| Live forecast overlays | Through the Konfersi server | Can be fetched directly by your computer |
