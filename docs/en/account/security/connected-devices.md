When you sign in from the Konfersi Lab extension in VS Code, Cursor, Antigravity or another editor, or use **Open in VS Code** on a project, that editor appears under **Connected devices**.

Open it from **Profile & Settings → Security → Connected devices**.

## What's listed

Each connected editor shows:

- the editor and the system it runs on, and the Konfersi Lab extension version
- the **Device** name, which you can change with **Rename**
- when it was **Last active** (or **Active now**) and where it was **Last seen from**
- when it was **Connected**

**Recently disconnected** lists editors that were disconnected by you, disconnected with all devices, or signed out in the editor.

## Disconnect an editor

- Select **Disconnect** next to an editor. It's signed out straight away and needs to sign in again.
- Select **Disconnect all** to sign out every connected editor at once.

Don't recognise a device, location or time? Disconnect it, then select **Change password**.

For setting up the extension, see [Lab workspace](../../using-konfersi/lab-workspace.md).
