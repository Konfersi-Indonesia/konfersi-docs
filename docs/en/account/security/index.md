Open **Profile & Settings → Security** in the Console side menu.

Sign-in starts with the top method that is turned on. The others appear under **Use another method** on the sign-in page. Google, GitHub and Microsoft sign-in skip these steps.

## Sign-in methods

| Method | How it works |
|---|---|
| **Emailed sign-in code** | Instead of your password, enter your email and Konfersi sends a one-time code |
| **Password + emailed code** | After your password, Konfersi emails a 6-digit code to confirm it's you. Only for accounts that sign in with a password |
| **Authenticator app** | After signing in, enter the code from an app such as Google Authenticator or 1Password |
| **Passkey** | Sign in with this device, a security key or a password manager |

The page tells you how many of these extra checks are on.

### Turn a method on

- **Emailed sign-in code**: select **Turn on**.
- **Password + emailed code**: select **Email me a code**, then enter the 6-digit code from the email to confirm.
- **Authenticator app**: select **Set up authenticator**, scan the QR code with your app (or enter the key manually), then enter the 6-digit code it shows.
- **Passkey**: select **Add a passkey** and follow your browser's prompt. You can add several, for example one per device, and remove any you no longer use.

To turn a method off, select **Turn off** and confirm.

### Change the order

Use the arrows next to each method to move it up or down. The top method that is on is marked **Default**.

## Password

To change your password, open **My Profile → Change Password**. Accounts that sign in only through Google, GitHub or Microsoft don't have a Konfersi password.

## Connected devices

Code editors you signed in through the Konfersi Lab extension are listed under **Connected devices**. See [Connected devices](connected-devices.md).

If you see a sign-in, device or location you don't recognise, disconnect it and change your password.
