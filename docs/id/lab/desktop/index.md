Ekstensi **Konfersi Lab** membawa seluruh ruang kerja Lab ke editor kode desktop. Ini ekstensi yang sama dengan yang menjalankan Lab di browser, jadi setiap tampilan, perintah, dan hasilnya sama.

Editor yang didukung: **VS Code** dan **Antigravity**. Editor lain berbasis VS Code (versi 1.90 atau lebih baru), seperti Cursor, juga bisa memasang ekstensi dari berkasnya.

## Browser atau desktop?

| | Browser | Editor desktop |
|---|---|---|
| Pemasangan | Tidak perlu | Pasang ekstensi sekali dari berkas |
| Masuk | Memakai sesi Console | Setujui editor sekali dari browser |
| Membuka proyek | **Konfersi Lab** di Console | **VSCode** atau **Antigravity** di Console, atau **Konfersi: Ganti Proyek…** |
| Menyimpan berkas (grafik, CSV, laporan, NetCDF) | Diunduh oleh browser | Disimpan lewat dialog simpan sistem |
| Pembaruan | Selalu terbaru | Ekstensi memperbarui dirinya sendiri |
| Overlay prakiraan langsung | Lewat server Konfersi | Bisa diambil langsung oleh komputer Anda |
